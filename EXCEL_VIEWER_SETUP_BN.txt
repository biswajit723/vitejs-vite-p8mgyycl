EXCEL VIEWER PATCH - REPORTS GENERATE TOOLS

What changed
- Added an EXCEL button to the existing ISO planning dashboard action row.
- Workbook files are selected and processed locally in the browser; no workbook file is embedded in this project archive.
- Supports .xlsm/.xlsx workbook selection and a numeric suffix after 4193_HH_Isometrics Control Sheet-Piping_OFSI.
- Shows the Dashboard replica and worksheet tabs; spreadsheet-style grid preserves available cell values, common styles, column widths and merged cells.
- Header names with MANUAL markers display without the marker; manual-editable columns are remembered by sheet and normalized header name in browser localStorage.
- The first three rows and detected header row are sticky in worksheet grid view.
- Export patches changed cells into the original workbook package so VBA, chart, pivot and slicer package parts are retained. Excel desktop macro/pivot/slicer behavior is not executed inside the browser viewer.

Apply the patch to an original, unpatched project
1. Copy excel-viewer-updater-safe.cjs into the project root (same folder as package.json).
2. Confirm src/app.jsx is the original project source, not a prior full-file replacement.
3. Run: node excel-viewer-updater-safe.cjs
4. Run: npm run build

The updater creates timestamped backups of src/app.jsx, package.json and package-lock.json. It is idempotent and refuses to patch unknown/partially patched layouts rather than replacing the app.

Alternatively, the src/app.jsx in this ZIP is already patched and fflate@0.3.11 is recorded in package.json and package-lock.json.

Limitations
- Browser rendering recreates the Dashboard UI from workbook data; it does not run VBA macros or fully emulate native Excel PivotTable/Slicer controls or formula recalculation. Excel desktop is asked to recalculate formulas/refresh pivot caches after a downloaded edit.
- Use a copy of your workbook containing data you are authorized to use. The workbook is not included in this archive.
